# Timeline

Dhiti started in June 2025 as a Next.js app with a survey-style career assessment. Later it was rebuilt as a conversational AI counsellor, with bigger trait and role models. These are the main milestones along the way, dated as precisely as the record allows.

| When | Milestone |
|---|---|
| **June 2025** | Project started (Next.js app). |
| **2025** | First product: a survey-style career assessment. |
| **2025–2026** | Rebuilt as a conversational AI counsellor. The trait model expanded from 8 to **18 traits**, and the role model from 25 to **30 roles**, so that every role in the scenario bank can be reached from matching. |
| **August 2026** | Role selection unblocked from the enrichment step. See [result 3](docs/13-results-and-measurements.md#result-3-role-selection-wait). |
| **September 2026** | Exam generation concurrency and time budget. See [results 1 and 2](docs/13-results-and-measurements.md#result-1-exam-generation-time). |
| **September 2026** | Credit-based access and the admin Overview metrics. |
| **September 2026** | Email-verified sign-up from a dedicated domain mailbox. |
| **September 2026** | Server-side pipeline orchestration. See [ADR-04](docs/11-engineering-decisions.md#adr-04-move-pipeline-orchestration-from-the-browser-to-the-server). |
| **Late September 2026** | About 340 commits to date. |
